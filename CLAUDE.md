# Project instructions

- Use `bun` and `bunx` instead of `npm` and `npx`.
- Use NativeWind or Tailwind for styling. Do not use raw HTML style attributes.
- Preserve existing quote styles; do not change quotes in unrelated code.
- Before committing or pushing to `main`, ask the maintainer to confirm that they have tested the app and it works. The maintainer generally prefers to push app changes manually.
